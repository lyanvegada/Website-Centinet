TU MISIÓN

Piensa como atacante. Aprende a detectar como defensor.

Has sido desplegado en una instancia de Kali Linux desde tu navegador y dentro de nuestra red de simulación. Se ha detectado un servidor corporativo comprometido por actores maliciosos, que dejaron múltiples puertas traseras.

Tu objetivo es infiltrarte en el servidor, identificar las vulnerabilidades y recuperar las cuatro banderas de información clasificada. Mientras avanzas, Centinet evaluará si sus defensas son capaces de detectar tus movimientos.

TU RECORRIDO

Cuatro retos. Una misión.

Avanza paso a paso, utiliza las pistas cuando las necesites y encuentra las flags que dejó el rastro de los atacantes.

01★Fácil
RECONOCIMIENTO · FUGA DE INFORMACIÓN

Mirando bajo la alfombra

Los atacantes modificaron la página principal del panel web corporativo, pero olvidaron borrar un directorio oculto que contiene información sensible en texto plano.

Ver pista técnica+

Abre Firefox dentro de Kali y visita el servidor objetivo:

http://centinet-ctf-target

Revisa la estructura de carpetas. Piensa qué nombre suelen tener los directorios ocultos o secretos en servidores web.

02★★★Intermedio
EJECUCIÓN DE CÓDIGO REMOTO

Entradas no sanitizadas

El equipo de desarrollo dejó un script llamado ping.php en la raíz del servidor web para hacer pruebas de red, pero no sanitizó las variables.

Ver pista técnica+

Visita el script y observa el parámetro cmd:

http://centinet-ctf-target/ping.php

Prueba a pasar un comando del sistema operativo por la URL:

http://centinet-ctf-target/ping.php?cmd=ls

Encuentra el archivo de texto sospechoso y lee su contenido.

03INTERCEPCIÓN · FUERZA BRUTA
SERVICIOS EXPUESTOS · EXFILTRACIÓN

Secretos en el aire

Creemos que los atacantes abrieron un servicio antiguo para exfiltrar archivos de forma remota.

Ver pistas técnicas+

Pista 1. Escanea los puertos y servicios abiertos:

nmap -sV centinet-ctf-target

Pista 2. Si encuentras FTP en el puerto 21, prueba las credenciales filtradas:

Usuario ftpuserContraseña ftp123

Pista 3. Utiliza wget para extraer el archivo desde el entorno restringido. La sintaxis general es:

wget ftp://usuario:contraseña@objetivo/archivo.txt

04★★★★★Difícil
ESCALADA DE PRIVILEGIOS · SUID

Escalada de privilegios

Hemos interceptado credenciales de bajo nivel de un empleado descuidado. Debes entrar al servidor, pero no tendrás permisos de administrador (root). Encuentra una vulnerabilidad en los binarios del sistema para escalar privilegios.

Ver pistas técnicas+

Pista 1. Conéctate por SSH desde tu terminal:

ssh sysadmin@centinet-ctf-target
Contraseña sysadmin

Pista 2. Busca binarios que tengan activado el bit SUID. Revisa:

/usr/local/bin/

Si encuentras una versión modificada de find, consulta GTFOBins para conocer cómo puede utilizarse para obtener una shell con permisos de root.

Pista 3. Cuando tengas permisos de root, busca la bandera en la carpeta personal del usuario.
